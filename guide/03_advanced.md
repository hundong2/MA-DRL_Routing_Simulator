# 03. 심화 실험·성능·재현성

## 재현 실험 설계

1. 코드 SHA, OS, Python, 패키지 lock, 입력 CSV, 전역 설정, 모델 SHA-256을 저장한다.
2. 학습/평가를 분리한다. 기본 `Train=True`이므로 `explore=False`만으로 학습이 정지한다고 단정하지 않는다.
3. 고정/이동 토폴로지, 부하 수준, 지상국 수를 하나씩 바꾼다. `movementTime`보다 긴 관측창에서 위치 변화 배율도 기록한다.
4. NumPy뿐 아니라 Python random·TensorFlow seed와 장치 결정성을 점검한다. 복수 seed 결과와 변동 폭을 보고한다.
5. 비교군의 동일 트래픽·초기 위치·평가 구간·생성 분모를 맞춘다. 도착 패킷 지연과 미도착 수를 함께 제시한다.

## 지연 통계 함정

`analyze_latency.py`는 실제 저장 컬럼 `Latency`(초)를 읽어 평균·median·nearest-rank p95(ms)를 계산한다. 기본 입력은 작성한 작은 CSV fixture이지 논문의 측정값이 아니다. 실제 실행 CSV를 인자로 넘길 수 있지만 과거 `Post-Processing/`의 다른 스키마는 먼저 확인해야 한다.

```sh
python guide/examples/analyze_latency.py "Results/<실행폴더>/csv/allLatencies_2_gateways.csv"
```

수신 완료 샘플만 읽으므로 전달률·손실률을 계산하지 않는다. 시뮬레이션 종료 순간 비행 중인 패킷은 곧바로 네트워크 손실이라고 볼 수 없다. 생성 수·완료 수·드롭 수·잔류 수를 구분하고 필요하면 생성 종료 뒤 drain 구간을 둔다. 평균만 낮아지고 드롭이 늘어나는 정책은 개선이라고 단정할 수 없다. p95 계산 정의와 표본 수도 남긴다.

## 코드 리뷰와 확장 지점

- 유지보수: 환경·토폴로지·정책·측정이 `SimulationRL.py`에 결합되어 있다. 리팩터링 시 먼저 고정 seed의 작은 trace 회귀 테스트를 만들고 모듈을 분리한다.
- 정확성: `updateSatelliteProcessesRL`의 오래된 이웃 문제를 추적한다. 유실 로그를 무시하지 말고 링크 변경 시점/블록 ID/이전·새 이웃을 기록한다.
- 학습: 현재 온라인 분기는 이전 hop의 agent를 `updateAgent`로 선택한다. 전이가 어느 agent의 buffer에 들어가는지 가장 먼저 테스트한다. 학습 함수의 실제 target과 loss가 의도한 DDQN인지 별도 수치 검증이 필요하다.
- 성능: 그래프 재생성, 위성별 NN, 순차 이벤트, Matplotlib 저장을 각각 계측한다. 복수 실험의 병렬 실행은 서로 다른 출력 경로를 사용하고 메모리 한도를 정한다.
- 정책 확장: 새 정책은 상태 인코딩→유효 행동→보상→다음 hop 인터페이스를 먼저 명세한다. 모델만 교체해도 상태/방향 순서가 달라지면 결과가 깨진다.
- 평가 확장: 부하와 토폴로지 seed를 학습 중 본 조건과 분리하고, reward 변화가 실제 latency·throughput에 미치는 영향도 따로 비교한다.

## 보안·라이선스 경계

이 코드에 서버 인증·클라우드 배포·외부 RPC 구조를 가정하지 않는다. 주요 경계는 로컬 CSV/지도/모델 입력과 결과 파일 쓰기다. 모델 역직렬화와 `allow_pickle=True` 객체 로드는 단순 데이터 읽기와 같은 안전성을 가정할 수 없다. 외부 H5/NPY를 임의로 실행하지 말고 출처·해시를 확인한 격리 환경에서만 검토한다. 예제는 텍스트 CSV와 AST 검사만 사용한다.

공개 GitHub와 ‘open source’라는 논문 제목만으로 코드 재배포 라이선스를 확정할 수 없다. 별도 LICENSE가 없는 현재 기준에서는 활용 전 저자 확인이 필요하다.

## 기여와 다음 단계

문제 제보에는 SHA·환경·최소 설정·실행 명령·오류 trace·seed를 포함한다. 사용자 요청 없이 본 문서 작업에서 물리 모델/학습 로직을 수정하지 않았다. 다음 순서는 SimPy 이벤트 모델 → 기준 Dijkstra 실험 → 학습 상태·보상 → 이동 회귀 테스트 → 반복 실험과 논문 표 비교다. [아키텍처 문서](../docs/archify/README.md)로 코드 근거를 찾는다.
